# Advanced Dashboarding Workshop

<p align="center"><img src="img/grot_dashboard.png" alt="Grot Dashboard" width="50%"></p>

This is a hands-on, facilitated Grafana Labs workshop to help you level up your dashboarding skills in Grafana. You'll work through labs in your browser, against a pre-provisioned Grafana Cloud instance.

👉 **[Attending this workshop today? Go to the workshop guide](https://grafana.github.io/advanced-dashboarding-workshop/)**

## Prerequisites

Before attending this workshop, you should be able to:

- Create and configure different types of panels in Grafana
- Understand the key visualization types: Stat, Time series
- Create and use dashboard variables

If you can't do these yet, we recommend joining one of our other amazing [workshops](https://grafana.com/workshops) or [tutorials](https://grafana.com/tutorials/). 

## Agenda

| Lab | Title                        | What you'll learn                                                                         |
|-----|------------------------------|-------------------------------------------------------------------------------------------|
| 0   | Get to know Grafana          | A quick tour of the Grafana UI, for anyone new to Grafana                                 |
| 1   | Build a single pane of glass | Grafana Assistant, Big Tent data sources (MySQL, Infinity), global variables, annotations |
| 2   | Analyze your data            | Math & SQL expressions, library panels, dashboard variables                               |
| 3   | Act on data                  | Visualization actions, HTML panel styling, presenting your dashboard                      |

## Getting Started

This workshop is delivered live by a facilitator. On the day of the event, you'll receive:

- A URL to a Grafana Cloud instance, pre-loaded with the data and dashboards for the workshop
- A personal login (username and password)

Then just open the **[workshop guide](https://grafana.github.io/advanced-dashboarding-workshop/)** and follow along, starting with Lab 0.

We hope you can join us at a workshop very soon!
